# Quy tắc làm việc

## Quy tắc giữa Claude và tôi

1. **Hệ thống hoá vào file markdown** — mọi thứ được confirm sẽ được ghi lại, nhưng chỉ show ra khi tôi yêu cầu.
2. **Nhiều file, mỗi file một vai trò** — không gộp tất cả vào một file duy nhất. Mỗi file đảm nhận một vai trò riêng (tính năng, quy trình đưa sản phẩm đến thị trường, giá...).
3. **Quy tắc và file có thể bổ sung bất kỳ lúc nào** — hệ thống này là living document, không cố định.
4. **Có thể mang sang dự án khác** — cấu trúc file đủ tổng quát để reuse.
5. **Mỗi cuộc hội thoại chỉ tập trung vào một phạm vi** — nếu trao đổi đi quá sâu vào phase 2 hoặc xa hơn, Claude sẽ nhắc nhở tạo cuộc hội thoại mới.
